==================================================
SELECCIÓN DE FECHA Y HORA DESPUÉS DE SUCURSAL
==================================================

Después de que el usuario elija su sucursal, debe seleccionar para qué fecha y hora quiere su pedido.

El flujo debe ser:

1. Elegir sucursal
2. Elegir fecha
3. Elegir hora
4. Entrar al catálogo
5. Comprar únicamente productos disponibles para esa sucursal, fecha y hora

La fecha y hora seleccionadas deben convertirse también en CONTEXTO de toda la sesión.

Guardar:

selected_branch_id
selected_date
selected_time

==================================================
1. FLUJO INICIAL
==================================================

Después de seleccionar:

Mallorca Reforma
o
Mallorca Lomas

mostrar inmediatamente:

"¿Para cuándo lo necesitas?"

[ Seleccionar fecha ]

Después:

"¿A qué hora?"

[ Seleccionar horario ]

CTA:

[ Ver productos disponibles ]

No entrar al catálogo hasta tener:

sucursal
fecha
hora

==================================================
2. CALENDARIO
==================================================

Mostrar calendario visual moderno y sencillo.

Debe permitir:

- seleccionar día
- navegar entre meses
- bloquear fechas no disponibles
- bloquear días cerrados
- bloquear días festivos o excepciones
- respetar horarios especiales por sucursal
- respetar anticipación mínima de productos

No permitir seleccionar fechas anteriores a hoy.

==================================================
3. DISPONIBILIDAD SEGÚN SUCURSAL
==================================================

El calendario debe depender de la sucursal elegida.

Ejemplo:

Mallorca Reforma
abre ciertos días/horarios

Mallorca Lomas
puede tener otros horarios

Por lo tanto:

las fechas y horarios disponibles deben calcularse según la sucursal activa.

==================================================
4. TIEMPO MÍNIMO DE PREPARACIÓN
==================================================

Cada producto debe poder tener:

minimum_lead_time

Ejemplo:

Croissant:
0 horas

Panettone:
24 horas

Pastel personalizado:
48 horas

Si el usuario selecciona:

Hoy 18:00

no mostrar como disponible un producto que requiere 48 horas.

==================================================
5. FILTRADO DEL CATÁLOGO
==================================================

Una vez seleccionados:

Sucursal:
Reforma

Fecha:
15 septiembre

Hora:
12:30

el catálogo debe mostrar sólo productos que realmente puedan entregarse o recogerse en ese momento.

Cada producto debe evaluarse considerando:

- sucursal
- stock
- tiempo de preparación
- horario
- disponibilidad por día
- fechas especiales
- producto temporal

==================================================
6. PRODUCTOS NO DISPONIBLES
==================================================

Preferencia:

mostrar productos no disponibles de manera opcional pero claramente deshabilitados.

Ejemplo:

Pastel personalizado

"No disponible para esta fecha"

"Disponible a partir del 17 de septiembre"

[ Cambiar fecha ]

Esto es mejor que ocultar completamente el producto si queremos permitir descubrimiento.

==================================================
12. PICKUP Y DELIVERY
==================================================

La fecha/hora elegida inicialmente debe servir como referencia para la compra.

Pero en checkout debe validarse nuevamente.

Si el usuario selecciona:

Pickup

mostrar:

Mallorca Reforma
15 septiembre
12:30

[ Cambiar ]

Si selecciona Delivery:

validar que esa fecha/hora también sea posible para entrega.

==================================================
13. DELIVERY TIME
==================================================

Para delivery se puede manejar:

franja horaria

Ejemplo:

12:00–13:00

en lugar de minuto exacto.

Dejar arquitectura preparada para:

pickup_slot

delivery_slot

como tipos diferentes.

26. CRITERIO FINAL
==================================================

La combinación:

Sucursal
+
Fecha
+
Hora

debe convertirse en el contexto operativo de toda la compra.

No permitir que el usuario añada productos que no puedan cumplirse para ese contexto.

Pero tampoco hacer que el sistema se sienta restrictivo.

Cuando algo no esté disponible:

explicar por qué
+
ofrecer automáticamente la siguiente fecha u horario posible.
